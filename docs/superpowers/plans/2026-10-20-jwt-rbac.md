# Task #12: JWT Validation + RBAC

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm authentication (JWT từ Auth0) và authorization (RBAC theo role) vào room-service, sau đó mở rộng sang booking-service. Health endpoints giữ public.

**Architecture:** JWT validation nằm trong `libs/common` (dùng chung cho mọi service). Mỗi request mang `Authorization: Bearer <token>` → middleware decode JWT bằng JWKS (RS256) → extract roles từ custom claim `https://mrms.api/roles` → FastAPI `Depends()` kiểm tra role. Auth0 là identity provider bên ngoài — service không lưu users, chỉ validate token.

**Tech Stack:** PyJWT + cryptography (RS256 verify), `httpx` (fetch JWKS), FastAPI Depends, pytest

**Spec:** `docs/auth0-setup.md` (roles + permissions + custom claims), CLAUDE.md §6 task #12

## Global Constraints

- Python 3.12, ruff lint, line length 100
- Sync SQLAlchemy only (no async)
- Health endpoints (`/health`, `/api/rooms/health`) luôn **public** — Docker healthcheck không có token
- Auth0 JWKS endpoint: `https://{domain}/.well-known/jwks.json` — cache trong memory (không fetch mỗi request)
- Custom claim namespace: `https://mrms.api/roles` (set bởi Auth0 Action, xem `docs/auth0-setup.md` §6)
- Roles (chuỗi trong JWT claim): `Employee`, `Room Manager`, `Administrator`
- M2M tokens (client_credentials) không có roles — chúng mang permissions trực tiếp; task này chỉ xử lý user tokens
- `AUTH0_DOMAIN` và `AUTH0_AUDIENCE` là 2 env vars bắt buộc khi bật auth; thiếu → service không khởi động

## Review Focus

1. **Token hết hạn:** `exp` claim phải được kiểm tra — test gửi token với `exp` trong quá khứ → 401
2. **Audience sai:** token từ Auth0 tenant khác (khác `aud`) → 401, không cho truy cập
3. **Role thiếu:** Employee gọi `DELETE /api/rooms/1` → 403, không 404 (authz trước business logic)
4. **Health endpoint không cần token:** `GET /api/rooms/health` không gửi `Authorization` → 200 (không 401)
5. **Token format sai:** `Authorization: Basic xxx` hoặc `Authorization: Bearer not.a.jwt` → 401 với message rõ ràng

### Task 1: JWT Validator trong libs/common

**Files:**
- Modify: `libs/common/src/common/config.py`, `libs/common/setup.py` hoặc `pyproject.toml`
- Create: `libs/common/src/common/auth.py`, `libs/common/tests/test_auth.py`

**Interfaces:**
- Produces:
  - `ServiceSettings.auth0_domain: str | None = None` — optional, service chạy không auth khi None
  - `ServiceSettings.auth0_audience: str | None = None`
  - `TokenPayload` dataclass: `sub: str`, `roles: list[str]`, `permissions: list[str]`, `exp: int`
  - `JWTValidator(domain: str, audience: str)` class:
    - `__init__` fetches JWKS từ `https://{domain}/.well-known/jwks.json` và cache
    - `decode(token: str) -> TokenPayload` — verify signature (RS256), exp, aud, iss; raise `AuthError`
  - `AuthError(Exception)`: `status_code: int`, `detail: str`
  - `require_roles(*allowed_roles: str) -> Callable` — FastAPI dependency factory; trả về `TokenPayload` nếu user có ít nhất 1 role trong `allowed_roles`; raise `AuthError(403)` nếu không
