# Task #13: Seed Data

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `make seed` tạo ~10 demo rooms vào `room_db` để có sẵn data cho demo và development. Idempotent — chạy lại không tạo duplicate.

**Architecture:** Script Python thuần dùng `psycopg` (driver đã có trong container) kết nối trực tiếp tới `room_db` qua `DATABASE_URL`. Dùng `INSERT ... ON CONFLICT DO NOTHING` trên partial unique index `uq_rooms_name_active` để đảm bảo idempotent. Chạy bằng `docker compose run --rm room-service python scripts/seed.py`.

**Tech Stack:** Python 3.12, psycopg (sync), PostgreSQL JSONB

**Spec:** `CLAUDE.md` §6 task #13, `docs/erd.md` §4 (rooms table)

## Global Constraints

- Python 3.12, ruff lint, line length 100
- Seed script phải idempotent: chạy N lần → kết quả giống chạy 1 lần
- Dùng `DATABASE_URL` env var (đã có trong Docker container)
- Migration phải chạy trước seed (`alembic upgrade head`)
- Không import app code (script standalone, chỉ dùng `psycopg` + `os` + `json`)

## Review Focus

1. **Idempotency:** Chạy `make seed` 2 lần → lần 2 insert 0 rows, không lỗi, không duplicate
2. **Equipment JSONB format:** Giá trị phải là JSON array of strings hợp lệ, không phải Python list literal
3. **Status constraint:** Tất cả rooms phải dùng status trong `('AVAILABLE', 'MAINTENANCE', 'ARCHIVED')` — giá trị khác sẽ vi phạm CHECK constraint
4. **Capacity constraint:** Tất cả rooms phải có `capacity > 0` — vi phạm CHECK constraint nếu ≤ 0
5. **Name uniqueness:** Không có 2 rooms cùng name trong seed data (sẽ vi phạm partial unique index)

- [ ] **Step 1: Write unit tests** `tests/test_seed.py`

Tests cho seed data definitions (import `SEED_ROOMS` từ `scripts/seed`):

```python
from scripts.seed import SEED_ROOMS

VALID_STATUSES = {"AVAILABLE", "MAINTENANCE", "ARCHIVED"}

def test_seed_rooms_not_empty():
    assert len(SEED_ROOMS) >= 10

def test_all_names_unique():
    names = [r["name"] for r in SEED_ROOMS]
    assert len(names) == len(set(names))

def test_all_capacities_positive():
    for r in SEED_ROOMS:
        assert r["capacity"] > 0, f"{r['name']} has capacity {r['capacity']}"

def test_all_statuses_valid():
    for r in SEED_ROOMS:
        assert r["status"] in VALID_STATUSES, f"{r['name']} has status {r['status']}"

def test_equipment_is_list_of_strings():
    for r in SEED_ROOMS:
        assert isinstance(r["equipment"], list)
        for item in r["equipment"]:
            assert isinstance(item, str)

def test_no_duplicate_equipment_per_room():
    for r in SEED_ROOMS:
        assert len(r["equipment"]) == len(set(r["equipment"])), r["name"]

def test_required_fields_present():
    required = {"name", "capacity", "status", "equipment"}
    for r in SEED_ROOMS:
        assert required.issubset(r.keys()), f"{r['name']} missing {required - r.keys()}"
```
